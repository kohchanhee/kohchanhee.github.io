# kohchanhee.github.io

Personal portfolio built with React, TypeScript, and Vite.

## Local Development

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

This repository is configured to deploy to GitHub Pages from GitHub Actions. Pushes to `main` build the site and publish the `dist` folder.
